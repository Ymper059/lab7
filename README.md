## Алгоритм и блок-схема

1. **НАЧАЛО**

2. Вывод меню:
   - `1` — Цифра или буква;
   - `2` — Калькулятор;
   - `3` — Римские цифры → год;
   - `0` — Выход.

3. Ввод значения `choice`.

4. Оператор `switch(choice)`:
   - `case 1` — вызов функции `task1()`;
   - `case 2` — вызов функции `task2()`;
   - `case 3` — вызов функции `task3()`;
   - `case 0` — вывод сообщения «Выход».

6. **КОНЕЦ**
